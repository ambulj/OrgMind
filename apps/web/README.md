# OrgMind Web Application (`apps/web`)

Next.js 14+ / TypeScript / Tailwind CSS / shadcn/ui frontend application providing:
- Clean content-first UI (zero glassmorphism, high contrast WCAG 2.2 AA).
- Cytoscape.js interactive graph view with focus mode and keyboard navigation.
- Evidence Drawer with verbatim source highlighting and attribution.
- As-of temporal time travel picker.
- Review Inbox for approving conflicting or incoming extractions.

Scaffolded in Phase 1; design system in docs/DESIGN.md; fully implemented in Phase 7.
